CYBERSAFE CAMPUS — WEBSITE PROTOTYPE

HOW TO RUN
1. Extract the ZIP file.
2. Open the CyberSafe-Campus folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Click the sidebar items to switch views within the same app-style interface.

FEATURES
- Single-page interface with in-app navigation (no long scrolling between sections).
- Phishing warning-sign estimator for pasted text/URLs; optional .txt/.eml/.csv file picker is secondary.
- Local password strength and estimated weakness checker.
- Identity-theft habit self-assessment without collecting identity details.
- Social engineering manipulation-sign estimator with optional text-file input.
- Interactive cyber safety checklist.
- Ten-question quiz with feedback, score, and restart.
- Step-by-step reporting guide and official India cybercrime resources.

IMPORTANT LIMITATIONS
This is an educational prototype, not a commercial detection system. Risk percentages are heuristic estimates based on text patterns or self-reported habits. They are not proof that a message is malicious or safe. The tool does not visit or verify websites, check leaked databases, or submit reports. Password checks run in the browser; do not use a password you rely on if you prefer not to enter it into a demo. For real incidents, use official channels and preserve evidence.
